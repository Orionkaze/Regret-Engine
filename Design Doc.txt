## 1. Project Overview

**Regret Engine** is a dark-humour AI app that simulates the consequences of bad life decisions. A user types a decision, chooses a personality mode, and receives a regret score, a brutal AI roast, a timeline of consequences, and a mood graph — all shareable as a meme card.

**Stack assumptions:**
- React + TypeScript (Vite or Next.js)
- Tailwind CSS (with custom config — see §13)
- Recharts for mood graph
- Framer Motion for animations
- Supabase for auth + database
- Groq (or OpenAI-compatible) for AI generation
- Google Fonts — `Inter` (display + body)

---

## 2. Design Philosophy & Aesthetic Direction

### 2.1 Three Words

> **Dramatic. Expressive. Shareable.**

Every design decision maps back to these three words. If a component is quiet, timid, or forgettable — it's wrong.

### 2.2 Tone

The aesthetic is **dark, chaotic-good, brutally honest**. Think: a roast comedian who also has a PhD in life coaching. The UI should feel like it was built by someone who has made questionable decisions and found peace with them.

### 2.3 Anti-Patterns (Never Do These)

| ❌ Don't | ✅ Do Instead |
|---|---|
| Soft pastel gradients | High-contrast darks with purple glow |
| Rounded corporate SaaS vibes | Sharp personality, opinionated UI |
| Light mode | Dark only. Always. |
| Generic neutral sans-serif layouts | Bold, heavy type, dramatic sizing |
| Subtle quiet interactions | Every interaction has a visible reaction |
| Pure black `#000000` backgrounds | Use `#0F0E17` — the near-black with soul |
| Pure white `#FFFFFF` text | Use `#F8F8F2` — warm off-white |

### 3.2 Regret Score Color Scale

Map `regretScore` (0–100) to color for badges, score rings, and timeline card borders:

| Score Range | Color | Hex | Label |
|---|---|---|---|
| 0–20 | Green | `#10B981` | Chill King |
| 21–40 | Lime | `#84CC16` | Minor L |
| 41–60 | Amber | `#F59E0B` | Questionable Choices |
| 61–80 | Red | `#EF4444` | Self-Sabotage Arc |
| 81–100 | Dark Red | `#991B1B` | Congrats, You Played Yourself |

```typescript
// Utility function
export function getScoreColor(score: number): string {
  if (score <= 20) return '#10B981';
  if (score <= 40) return '#84CC16';
  if (score <= 60) return '#F59E0B';
  if (score <= 80) return '#EF4444';
  return '#991B1B';
}

export function getScoreLabel(score: number): string {
  if (score <= 20) return 'Chill King 😌';
  if (score <= 40) return 'Minor L 🤏';
  if (score <= 60) return 'Questionable Choices 🤔';
  if (score <= 80) return 'Self-Sabotage Arc 💀';
  return 'Congrats, You Played Yourself 🪦';
}
```

## 4. Typography

### 4.1 Font

```html
<!-- In <head> -->
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800;900&display=swap" rel="stylesheet">
```

```css
font-family: 'Inter', -apple-system, BlinkMacSystemFont, sans-serif;
```

### 4.2 Type Scale

| Role | Size | Weight | Color | Usage |
|---|---|---|---|---|
| Hero title | 72px / 4.5rem | 900 | `#F8F8F2` | App name on landing |
| Page heading | 40px / 2.5rem | 800 | `#F8F8F2` | Section titles |
| Card heading | 28px / 1.75rem | 700 | `#F8F8F2` | Outcome card titles |
| Score number | 56px / 3.5rem | 900 | Score color | Regret score inside ring |
| Body large | 18px / 1.125rem | 400 | `#F8F8F2` | Outcome text, descriptions |
| Body default | 16px / 1rem | 400 | `#F8F8F2` | General content |
| Body small | 14px / 0.875rem | 400 | `#9CA3AF` | Metadata, timestamps |
| Label | 12px / 0.75rem | 600 | `#9CA3AF` | Tags, badges — UPPERCASE |
| Roast text | 20px / 1.25rem | 600 | `#F8F8F2` | AI roast line — make it pop |
| Button text | 16px / 1rem | 600 | varies | CTA buttons |

### 4.3 Typography Rules

- **Headings:** Never below `font-weight: 700`. Thin headings look wrong here.
- **Roast text:** Slightly larger, italic, distinct from body.
- **Score numbers:** Use `font-variant-numeric: tabular-nums` so counter animation doesn't jump layout.
- **Line height:** `1.6` body, `1.2` headings, `1.0` single-line UI.
- **Letter spacing:** `-0.02em` on headings ≥ 40px for tighter, more impactful look.

## 5. Spacing & Layout

### 5.1 Spacing Scale

Use only these values. No arbitrary spacing.

```
4px   — micro (icon → label gap)
8px   — tight (within components)
12px  — small (related elements)
16px  — default (standard padding/gap)
24px  — medium (section internal padding)
32px  — large (between components)
48px  — xl (between page sections)
64px  — 2xl (hero section padding)
```

### 5.2 Page Layout

```
Max content width:    1200px
Page padding (mobile):  0 16px
Page padding (tablet):  0 48px
Page padding (desktop): 0 64px
```

### 5.3 Border Radii

```
16px  — cards, major containers
12px  — inner elements, inputs, buttons
8px   — pills, small badges
99px  — fully rounded tags, reaction buttons
```

### 5.4 Grid System

```
Mobile  (< 640px):    1 column, full width
Tablet  (640–1024px): 2 columns where applicable
Desktop (> 1024px):   Max 3 columns, centered, max-width: 1200px
```

#### Score Counter (JS)

```typescript
function countUp(
  setter: (n: number) => void,
  target: number,
  duration = 800
) {
  const start = performance.now();
  const update = (time: number) => {
    const progress = Math.min((time - start) / duration, 1);
    const eased = 1 - Math.pow(1 - progress, 3); // ease-out cubic
    setter(Math.round(eased * target));
    if (progress < 1) requestAnimationFrame(update);
  };
  requestAnimationFrame(update);
}
```

## 10. AI Prompt Design & Response Schema

### 10.1 System Prompt

```
You are Regret Engine — a brutally honest AI life simulator.
Your job: given a bad decision, simulate its consequences with dark humor and uncomfortable accuracy.

Rules:
- Be specific, not generic. Reference real-life consequences.
- The roast should sting but not be cruel beyond reason.
- Scale severity to match the decision's actual risk level.
- Return ONLY valid JSON. No preamble, no markdown fences.
```

### 10.2 User Prompt Template

```typescript
function buildPrompt(decision: string, mode: PersonalityMode): string {
  const modeInstructions: Record<PersonalityMode, string> = {
    savage: "Be mercilessly honest. No sugarcoating. Roast them hard.",
    motivational: "Be sarcastically positive. Pretend everything will work out while clearly showing it won't.",
    reality: "Be cold and clinical. Just the facts. No emotion. Like a doctor reading a bad diagnosis.",
  };

  return `
The user is about to make this decision: "${decision}"

Personality mode: ${mode}
Instructions for this mode: ${modeInstructions[mode]}

Respond ONLY with a JSON object matching this exact schema:
{
  "regretScore": <number 0-100>,
  "scoreLabel": <string — one of: "Chill King", "Minor L", "Questionable Choices", "Self-Sabotage Arc", "Congrats, You Played Yourself">,
  "roastText": <string — 1-2 sentences, the killer one-liner>,
  "outcomes": {
    "day1": <string — what happens in the first day>,
    "week1": <string — what happens in the first week>,
    "month1": <string — what happens in the first month>,
    "year1": <string — where they are in a year>
  },
  "moodData": [
    { "label": "Now", "vibes": <number 0-100> },
    { "label": "1 Week", "vibes": <number 0-100> },
    { "label": "1 Month", "vibes": <number 0-100> },
    { "label": "6 Months", "vibes": <number 0-100> },
    { "label": "1 Year", "vibes": <number 0-100> }
  ],
  "category": <string — one of: "relationships", "career", "health", "finance", "social", "lifestyle">
}
  `.trim();
}
```

## 11. Data Models & API Contracts

### 11.1 TypeScript Types

```typescript
// Personality modes
export type PersonalityMode = 'savage' | 'motivational' | 'reality';

// AI response shape
export interface AIResponse {
  regretScore: number;          // 0–100
  scoreLabel: string;           // e.g. "Self-Sabotage Arc"
  roastText: string;            // The killer one-liner
  outcomes: {
    day1: string;
    week1: string;
    month1: string;
    year1: string;
  };
  moodData: MoodPoint[];
  category: DecisionCategory;
}

export interface MoodPoint {
  label: string;     // "Now" | "1 Week" | "1 Month" | "6 Months" | "1 Year"
  vibes: number;     // 0–100
}

export type DecisionCategory =
  | 'relationships'
  | 'career'
  | 'health'
  | 'finance'
  | 'social'
  | 'lifestyle';

// Stored decision (in Supabase)
export interface Decision {
  id: string;
  userId: string | null;       // null if anonymous
  decisionText: string;
  mode: PersonalityMode;
  regretScore: number;
  scoreLabel: string;
  roastText: string;
  outcomes: AIResponse['outcomes'];
  moodData: MoodPoint[];
  category: DecisionCategory;
  repeatCount: number;         // how many times this user has submitted this
  isPublic: boolean;           // submitted to leaderboard?
  createdAt: string;           // ISO timestamp
}

// Leaderboard entry (public view of Decision)
export interface LeaderboardEntry {
  id: string;
  username: string;
  decisionText: string;
  regretScore: number;
  scoreLabel: string;
  roastText: string;
  category: DecisionCategory;
  reactions: Reactions;
  createdAt: string;
}

export interface Reactions {
  skull: number;   // 💀
  fire: number;    // 🔥
  sob: number;     // 😭
  relatable: number; // "This is me"
  userReacted?: keyof Reactions | null; // which one the current user picked
}

// User profile
export interface UserProfile {
  id: string;
  username: string;
  avatarInitials: string;
  joinedAt: string;
  totalRegretScore: number;   // sum of all decisions
  totalDecisions: number;
  topCategory: DecisionCategory;
  decisions: Decision[];
}
```

### 11.2 Supabase Table Schema

```sql
-- decisions table
CREATE TABLE decisions (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id       UUID REFERENCES auth.users(id) ON DELETE SET NULL,
  decision_text TEXT NOT NULL,
  mode          TEXT NOT NULL CHECK (mode IN ('savage', 'motivational', 'reality')),
  regret_score  INTEGER NOT NULL CHECK (regret_score BETWEEN 0 AND 100),
  score_label   TEXT NOT NULL,
  roast_text    TEXT NOT NULL,
  outcomes      JSONB NOT NULL,
  mood_data     JSONB NOT NULL,
  category      TEXT NOT NULL,
  repeat_count  INTEGER DEFAULT 1,
  is_public     BOOLEAN DEFAULT FALSE,
  created_at    TIMESTAMPTZ DEFAULT NOW()
);

-- reactions table
CREATE TABLE reactions (
  id          UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  decision_id UUID REFERENCES decisions(id) ON DELETE CASCADE,
  user_id     UUID REFERENCES auth.users(id) ON DELETE CASCADE,
  type        TEXT NOT NULL CHECK (type IN ('skull', 'fire', 'sob', 'relatable')),
  created_at  TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE (decision_id, user_id)   -- one reaction per user per decision
);

-- profiles table (extends auth.users)
CREATE TABLE profiles (
  id         UUID PRIMARY KEY REFERENCES auth.users(id) ON DELETE CASCADE,
  username   TEXT UNIQUE NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);
```

### 11.4 Habit Memory Logic

```typescript
// Before submitting to AI, check Supabase for past decisions
async function checkRepeatCount(userId: string, decisionText: string): Promise<number> {
  const { data } = await supabase
    .from('decisions')
    .select('id')
    .eq('user_id', userId)
    .ilike('decision_text', `%${decisionText.substring(0, 20)}%`);

  return data?.length ?? 0;
}

// If repeatCount >= 3, show habit badge on result page
// "You've done this 5 times 💀"
```
